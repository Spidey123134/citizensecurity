Estado al 3 de octubre de 2026. La entrega oficial de la línea `0.2` es **0.2.1**, sobre la interfaz y el splash del compañero. El botón de desarrollador y **admin / admin** dan acceso local a recepción, validación y pruebas de coordenadas de fases 1 y 2. [Release v0.2.1](https://github.com/Spidey123134/citizensecurity/releases/tag/v0.2.1). **Fase 3 / 0.3.0 y fase 4 / 0.4.0 siguen en Unreleased**; 0.4 continúa en una rama separada.

**Implementado**, **probado** y **revisado por el usuario** son estados distintos. La base de lógica y datos ya tiene código y pruebas; eso no significa que el usuario haya aceptado cada paso. Después de revisar la fase actual se elige el siguiente incremento.

## Reparto y siguiente paso

Las interfaces, el menú, la navegación y el login corresponden al compañero (`vazdavr-sudo`). El acceso local de demostración `admin / admin` fue solicitado por el usuario. La autenticación real sigue pendiente y se acordará antes de conectarla a servicios o cuentas. Los contratos y la composición compartida de dependencias se coordinan entre ambos, según [Trabajo del equipo](TRABAJO_EQUIPO.md).

El usuario autorizó acoplar la interfaz a nuestra lógica: el puente técnico de [Acoplar interfaz](ACOPLAR_INTERFAZ.md) está implementado y comprobado. El compañero puede conectar después su formulario y mostrar los estados del guardado. Las pruebas técnicas no aceptan funcionalmente esa pantalla ni entregan fase 3. Su código adelantado se conserva para `0.3.0 — Unreleased`. La integración visual de Google Maps sigue siendo una línea acordada posterior.

El splash y el login visual del compañero se conservan. La comprobación actual incluye 14 JVM de app, 9 instrumentadas SQLite, lint y compilación debug/release; las 32 de dominio conservaron su resultado mediante `UP-TO-DATE`. [Funciones publicadas](FUNCIONES_PUBLICADAS.md) describe los controles; [Validación](VALIDACION.md) registra la prueba visual del botón y del acceso de demostración. Las herramientas no entregan fases 3 o 4. La revisión funcional del usuario y las comprobaciones en teléfono físico y API 26 siguen pendientes.

## Alcance pendiente de acuerdo

La conexión de Google Maps requiere definir el SDK, proyecto de Google, clave y facturación antes de implementarla. Captura GPS, fotografías, sincronización, servidor, administración y notificaciones quedan pendientes de un nuevo acuerdo de alcance. El guardado actual es local. El proyecto anterior y su respaldo se conservan como referencia, y solo se reutilizan las partes necesarias para el incremento elegido.
